# Visual & Design Rules (Standing Preferences from Boss)

Last updated: `2026-11-18`

These visual rules apply across **all websites (`evacheecks.github.io`), client previews (`scripts/generate_client_page.py`), Fiverr gig gallery slides (`scripts/generate_b2b_excel_pack.py`), Instagram Reels (`Reels 02–07+`), and static marketing assets**:

1. **NO Outlines Around Every Element, Card, Pill, or Chip (`CRITICAL`):**
   - Never wrap cards, panels, feature bullets, comparison boxes, badges, pills, avatars/monograms, or interactive chips in full perimeter `border` / `outline` strokes (`1px solid ...`, `1.5px solid ...`, `2px` outlines).
   - Separate surfaces using **tonal fill contrast** (e.g., white `#ffffff` card on warm cream `#faf6ee`, elevated `#232629` panel on `#1b1d1f` slate, flat borderless dark tint on emerald background), **whitespace/padding**, or **soft ambient shadows** (`box-shadow`).
   - Simple horizontal section rules (`border-top` / `border-bottom` between menu categories or footer) and plain ink inputs with accessible `:focus` rings remain allowed for readability.

2. **NO Headline "Biscuit Pills":**
   - Do not put rounded pill badges with colored borders or dots right above main headlines.
   - Use crisp uppercase letter-spaced plain typography instead (e.g., `RED HOOK, BROOKLYN` or `CAFÉS & BAKERIES`).

3. **Hardware Mockups (`Entry 13`):**
   - Use generic **dark-graphite punch-hole Android** phone frames only (never iPhone Dynamic Island or notch). Leave a clean status-bar buffer at the top so headlines never collide with the camera dot.

4. **Typography & Uniqueness (`Entry 18`):**
   - Every client site gets its own adapted palette and type hierarchy — never clone one boxed template layout across businesses.
